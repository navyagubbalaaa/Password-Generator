# Password Generator 🔐

A simple Java Swing-based Password Generator application that creates secure random passwords based on user-selected criteria. Users can specify the password length and choose to include uppercase letters, lowercase letters, numbers, and special characters. The application uses Java's `SecureRandom` class to generate stronger random passwords and provides a simple graphical user interface.

### Features

* Generate random passwords
* Select password length
* Include uppercase and lowercase letters
* Include numbers and special characters
* Input validation and error handling
* User-friendly Java Swing GUI
* Uses `SecureRandom` for secure random generation

### Technologies Used

* Java
* Java Swing
* AWT
* SecureRandom
